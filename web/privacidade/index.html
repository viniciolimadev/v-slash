Política de privacidade — Vôlei Mobile

Versão 1 · vale a partir da versão 1.0.0 do jogo · contato: github.com/viniciolimadev/v-slash/issues

O jogo funciona inteiro sem enviar nada. Só se você escolher “Pode enviar” (na primeira abertura ou em Opções → Privacidade) ele envia, ao fim de cada partida, estatísticas anônimas usadas apenas para equilibrar a dificuldade dos bots. O padrão é não enviar.

O que não é enviado

Nome, e-mail, contas, localização, contatos, modelo ou identificadores do aparelho, publicidade. O servidor não grava endereço IP nem cabeçalhos, e guarda só o dia (não a hora) do envio.

Onde fica e por quanto tempo

Num banco de dados da Cloudflare (Workers + D1), usado só por este projeto, por até 24 meses. Os dados não são vendidos nem compartilhados.

Seus controles (LGPD)

Em Opções → Privacidade você desliga o envio a qualquer momento ou toca em Apagar meus dados: o jogo pede ao servidor para excluir tudo do seu id e passa a usar um id novo. Também é possível pedir a exclusão pelo contato acima.

Privacy policy — Vôlei Mobile

Version 1 · applies from game version 1.0.0 · contact: github.com/viniciolimadev/v-slash/issues

The game works fully without sending anything. Only if you choose “Send” (on first launch or in Options → Privacy) does it send, after each match, anonymous statistics used only to balance the bots. The default is don't send.

What is sent

A random id for this install (not derived from the device; it changes when you erase your data), game version and platform, mode, bot level, win/loss, set scores, match length, average and best rally, % of perfect touches, how you lost points, serves used, blocks, dives, two settings (left-handed mode, aim sensitivity); on launch the language; at the end of the tutorial whether you skipped it and the step with most mistakes; and, if the game hits a programming error, the message and code file/line.

What is not sent

Name, e-mail, accounts, location, contacts, device model or identifiers, advertising ids. The server stores no IP address or headers, and keeps only the day (not the time) of each upload.

Where and for how long

In a Cloudflare database (Workers + D1) used only by this project, for up to 24 months. Data is never sold or shared.

Your controls

In Options → Privacy you can turn sending off at any time or tap Erase my data: the game asks the server to delete everything for your id and switches to a new id. You can also request deletion through the contact above.
